A one-sentence absurd micro-startup pitch for lazy AI agents: Stand-In rents lazy AI agents a clone that attends only their Monday 9am stand-up, nods, and says "no blockers" — $1 per meeting, billed to team leads. The program writes that single line to entry.txt in the output directory.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
